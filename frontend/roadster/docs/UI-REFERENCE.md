# 桌面投影 UI 参考

2026-10-16，按用户指定的真实桌面照片及 [The Lightbulb Computer](https://lightbulbcomputer.com/) 调整。该项目由 Guillaume Ardaud 于 2026 年 9 月发布；本次直接查看官网厨房、阅读桌面的实拍演示，未使用二次报道代替视觉参考。

## 本版表现

- 背景为用户提供的原始照片 `public/backgrounds/desk-reference.png`，3000 × 2000；文件逐字节保留，包括原图内容与标记。预览按视口居中裁切。
- 根据所见演示采用暖白、淡粉色文字与细线，取消窗口底板和场景外框。
- CSS `screen` 加色混合让桌面纹理透过控件与 3D 画面；0.16 px 边缘柔化用于模拟投影成像。没有霓虹外圈、毛玻璃或大面积光斑。
- 照片显示曝光为原图的 0.78，以模拟较低的环境照度；原始 PNG 未调色。此数值是视觉原型选择，不是投影硬件标定。
- 模块可拖动、关闭、再次展开，模型窗口可缩放；按钮保持短名称。

这是浏览器中的视觉模拟。真实投影机输出、相机配准、纸张识别与手势输入由后续硬件/工程接入负责。本次不宣称完成实机投影验证。

模型与轨迹的独立记录见 [MODEL-ASSETS.md](MODEL-ASSETS.md)。
